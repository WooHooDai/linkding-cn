# 书签健康检查

批量探测书签链接是否仍然可达、是否被反爬拦截、或内容已失效（软 404，即返回 200 但内容已无法获取）。

- **纯手动**触发，不会定时执行，也不在保存书签时自动执行
- 结果只作提醒，不会自动删除或归档任何书签

## 如何使用

1. 单条书签检查：`书签工具栏`或`书签详情弹窗`中点击`检查`按钮即可
2. 多条书签批量检查：点击`批量编辑`按钮，勾选要检查的书签，选择`检查健康`，执行即可
3. 智能过滤器（Bundle）中书签批量检查：进入智能过滤器管理页面，点击要检查的智能过滤器右侧的`检查健康`按钮

> 同一时间只能运行一个检查任务，任务进度可在页面右下角进度胶囊中查看，任务运行中可暂停、继续、中止。

## 健康状态含义

书签的健康状态将在书签工具栏和书签详情弹窗中显示

| 状态 | 含义 | 常见原因 |
|------|------|----------|
| 正常 | 可达且内容正常 | — |
| 死链 | 确认失效 | HTTP 404/500、重定向循环 |
| 被拦截 | 反爬/登录墙拦截 | HTTP 401/403/407/429 |
| 内容丢失 | 返回 200 但页面已不存在 | 软 404（Google 官方术语） |
| 检查失败 | 网络层错误 | DNS 失败、连接超时、TLS 错误 |
| 未检查 | 从未检查过，或该域名禁用了健康检查 | — |

## 结果有效期

- 超过结果有效期的健康状态被视为`未检查`
- 默认 15 天，设置为 0 意味着永不过期
- 在`设置 - 通用 - 设置 - 健康检查`中配置

## 按站点定制

多数站点无需配置即可工作。
有特殊需求的站点，可通过 [Site Adapters](site-adapters.md#health) 的 health 字段进行定制

```jsonc
"domains": {
  "zhihu.com": {
    "health": {
      "http_head_probe": {
        "blocked_status": [403, 429]
      }
    }
  }
}
```
